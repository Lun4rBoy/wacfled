# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-08-29
### Added
- Initial release of the project with all basic features.
- Initial documentation.
  
### Errors
- Randomly the controller stops responding and needs a manual restart (disconnect and connect the plug)
- The commands to adjust brightness and speed are executed correctly but do not deliver any response and the fetch remains pending.

## [1.0.1] - 2024-12-27
### Added
- CRT monitor model added to replace the plain console
- Automatic search for compatible devices

### Fixes
- Fixed a problem where the controller freezes and required a manual reset
  
### Errors
- The search function has minor problems, in the first run it does not detect devices.
